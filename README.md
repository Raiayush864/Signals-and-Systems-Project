## Project Description
This project demonstrates the generation and analysis of continuous-time and discrete-time sine and cosine signals using Python.

## Objectives
1. To generate continuous-time sine and cosine signals.
2. To generate discrete-time sine and cosine signals.
3. To understand the difference between continuous and discrete signals.
4. To visualize signals using Python graphs.

## Tools and Libraries
- Python
- NumPy
- Matplotlib

## Simulation Parameters
- Amplitude: 1
- Frequency: 5 Hz
- Sampling Frequency: 40 Hz
- Time Duration: 1 second

## How to Run
1. Install the required libraries:
   pip install numpy matplotlib
2. Run the Python file:
   python3 signal_simulation.py

## Output
The simulation generates four graphs:
- Continuous-Time Sine Signal
- Discrete-Time Sine Signal
- Continuous-Time Cosine Signal
- Discrete-Time Cosine Signal

## Conclusion
The project successfully demonstrates the generation and visualization of continuous-time and discrete-time signals using Python.
